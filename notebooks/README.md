# Notebooks

Install `requirements-dev.txt`. Open from this folder or repository root; the bootstrap locates the complete repository. Retain `scripts/` alongside the notebooks.

| Notebook | Activity |
|---|---|
| [01](01_statistical_mechanics_and_integrators.ipynb) | Boltzmann populations, harmonic MC and Verlet stability |
| [02](02_lj_structure_and_dynamics.ipynb) | Executed LJ dynamics, RDF and unwrapping comparison |
| [03](03_uncertainty.ipynb) | AR(1) autocorrelation, blocking and interval assumptions |
| [04](04_mc_gcmc_kmc.ipynb) | Poisson GCMC limit and time-weighted KMC |
| [05](05_umbrella_wham.ipynb) | Umbrella windows, WHAM and overlap |
| [06](06_resources_and_quantum.ipynb) | Resource arithmetic and analytical quantum-oscillator variance |

Recorded outputs come from Python-cell execution in fresh namespaces without Jupyter sockets; see [validation](../VALIDATION_REPORT.md). Interactive kernel behavior was not verified here. The standard runner supports a normal Jupyter kernel on your own environment. No notebook downloads private data or writes to an external service.
